# 智能评审 Agent · 研发计划（任务分解）

日期：2026-09-30 ｜ 依据：PRD-v1.1 + v8 原型 ｜ 技术栈：LangGraph + FastAPI + React 19 + Ant Design X

---

## 总体策略

**最小闭环优先**：先打通"上传→识别→确认→模板→流式生成→Word"主链路，再扩展管理页与增强能力。

---

## 阶段一：最小闭环（骨架 + 主链路）

### 1.1 项目骨架搭建
- [ ] 创建 `backend/` FastAPI 项目结构（api / graph / services / models / schemas / core）
- [ ] 创建 `frontend/` React 19 + Vite + TS + Ant Design 5 + X 项目结构
- [ ] 配置 YAML 加载器（Pydantic Settings + .env）
- [ ] SQLite + SQLAlchemy + Alembic 初始化
- [ ] LangGraph StateGraph + SqliteSaver 基础图结构

### 1.2 文件解析（F1）
- [ ] 五类解析器：docx（python-docx）/ pdf（PyPDF2）/ xlsx（openpyxl）/ pptx（python-pptx）/ txt-md
- [ ] 统一解析结果模型（结构化文本 + 锚点信息）
- [ ] 文件大小上限校验与错误处理
- [ ] 上传 API + 解析结果返回

### 1.3 规则识别（F2，BR-2）
- [ ] 关键词规则引擎（六类类型 + 9 类子领域 + 阶段关键词）
- [ ] 年份识别（2024-2029，取最早）
- [ ] 组合评审判定（BR-3 行位置切分）
- [ ] 识别结果模型（含置信度与命中关键词）

### 1.4 模板匹配（F4，BR-1）
- [ ] 四套评分模板 YAML 配置（维度/权重/说明）
- [ ] 模板匹配逻辑（应用基础标志 × 阶段）
- [ ] 模板临时修改接口（任务级覆盖，不改全局配置）

### 1.5 LangGraph 人工确认门
- [ ] interrupt①：识别确认门（信息确认页数据交互）
- [ ] interrupt②：生成结果确认门（专家评审页定稿）
- [ ] Command(resume) 断点恢复机制

### 1.6 范文检索（F12，规则过滤优先）
- [ ] 范文数据模型 + 78 条初始数据导入脚本
- [ ] 规则过滤：类型 + 阶段 + 子领域
- [ ] 语义排序占位（bge-m3 接口预留，阶段二实现）

### 1.7 LLM 流式生成（F6）
- [ ] OpenAI 兼容客户端封装（内网 Gateway）
- [ ] 分维度 Prompt 模板（按 BR-5 规范）
- [ ] SSE 流式推送（FastAPI SSE）
- [ ] 错误处理与重试机制

### 1.8 Word 打分表生成（F8，BR-4）
- [ ] 空白打分表模板解析（OOXML 直写）
- [ ] 合并单元格填充（左总结右立项）
- [ ] 维度意见"√ 维度名=权重分意见：xxx"格式填充
- [ ] 备用通用排版（无模板时降级）

### 1.9 专家评审页前端（F16/F17/F18）
- [ ] 四步流水线步骤条（可点击回退）
- [ ] 左 3:2 布局：材料原文阅读器（锚点高亮）
- [ ] 右四页签：AI 评审结果 / AI 对话 / 评审报告 / 生成产物
- [ ] 维度卡片（评分区间条 + 专家打分输入 + 修改意见）
- [ ] 生成产物：文件级版本列表 + 历史版本下载
- [ ] 任务切换器（搜索下拉）+ 状态标签退出确认

### 1.10 任务列表页
- [ ] 多条件筛选（类型/阶段/状态/关键词）+ 查询/重置
- [ ] 分页器
- [ ] 行点击恢复任务断点
