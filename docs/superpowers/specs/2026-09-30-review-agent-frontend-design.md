# 智能评审 Agent · 前端原型设计规格

日期：2026-09-30 ｜ 范围：前端原型（mock 数据，后续接真实后端）｜ 依据：docs/PRD-v1.0.md

---

## 1. 设计目标

为"智能评审 Agent"提供一套**高保真、可交互的前端原型**，用于向业务部门对齐产品形态，并作为后续接入真实后端的实现蓝本。定位是"评审秘书"而非"AI 评委"——AI 生成草稿，所有关键环节有人工确认门。

## 2. 技术栈（已定稿，不变）

- React 19 + Vite + TypeScript
- Ant Design 5 + Ant Design X（@ant-design/x ^2.9 + x-markdown + x-sdk，useXChat + XStream 对接 SSE）
- 原型阶段：纯前端 + mock 数据，无需后端

## 3. 信息架构（四个一级页面）

| 页面 | 职责 | 对应 FR |
|------|------|---------|
| 工作台 | 评审全流程主界面（四步流水线） | FR-1~FR-9 |
| 任务列表 | 全部任务的独立列表模块 | FR-9 / FR-10 |
| 配置管理 | 模板/识别规则/范文库/检索参数 | FR-14 |
| 评审标准说明 | BR-1~BR-5 只读文档页 | FR-15 |

顶栏统一承载：logo、任务切换器（搜索下拉）、四个菜单、主题切换、用户头像。

## 4. 工作台：四步流水线

```
① 新建任务 → ② 信息确认 → ③ AI处理中 → ④ 专家评审
```

步骤条为**可点击导航**：已完成步骤可回退（弹确认框），当前步高亮，未到步置灰。步骤③在进入④后变为"↻ 点击重新评审"入口。

### ① 新建任务
- **上传即建任务**：上传文件那一刻自动创建任务（以识别到的项目名命名），无独立表单页。
- 布局：左侧大上传区（拖拽/点选，列文件清单）+ 右侧"最近任务"看板（3 张卡片，点击断点续评）。
- **此页不显示顶部步骤条**，进入下一步才加载。

### ② 信息确认（识别 + 模板合并）
- 左卡：识别结果六项（项目名称/项目类型/评审阶段/子领域/评审年份/是否应用基础类），各带置信度，可修改，修改留痕。下方展示命中关键词。
- 右卡：BR-1 模板匹配结果（组合评审命中两套），每张模板卡可「预览/修改」——展开维度名、权重（改时实时校验合计=100）、每维度评审说明文字（均可改）。
- 附「评审规则」卡片，可查看/修改 BR-2/3/5 规则全文。
- 底部「✓ 确认，开始 AI 评审」= 人工确认门①。

### ③ AI 处理中
- 逐维度生成进度（转圈→打勾+耗时）、流式输出打字机预览、总进度条。
- 期间断点自动保存，可随时退出。
- 完成后自动进入专家评审。

### ④ 专家评审（主工作台，左右 3:2）
- **左**：材料原文阅读器（纸张质感，支持锚点高亮定位）。
- **右**：四个页签。
  1. **AI 评审结果** —— 顶部合计条（AI 总分区间 + 专家实时打分合计 + 范文参照）+ 组合评审"立项/总结"切换。每个维度卡片：维度名+权重+AI 建议区间、评分区间可视化条、结论（可改）、原文依据锚点（点击左侧定位）、可折叠评审过程、**专家打分输入框**（超权重自动截断）+「✎ 修改意见」。
  2. **AI 对话** —— 追问 AI（useXChat + XStream），带快捷追问气泡。
  3. **评审报告** —— 可编辑正文（contenteditable），自动保存（仅 toast 提示）。
  4. **生成产物** —— **版本按文件维度独立管理**：每个文件（立项打分表/总结打分表/意见.md）有自己的版本线，可展开历史版本逐个下载；顶部"一键下载当前版本（ZIP）"。
- 底部常驻人工确认门②：「↻ 重新 AI 评审」（弹窗可附**修改建议**引导重评）+「✓ 定稿并生成产物」。

## 5. 任务全生命周期

- **新建**：上传即建。
- **切换**：顶栏任务切换器，搜索下拉，状态圆点（●待确认/◐处理中/○草稿/✓已完成），点击恢复断点。
- **保存**：默认自动保存，界面无独立控件，仅 toast 提示"✓ 已自动保存 HH:MM:SS"。
- **退出**：点顶栏任务状态标签 → 确认弹窗（显示当前进度，告知已自动保存可恢复）。

## 6. 任务列表（独立模块）

纯表格：项目名称 / 类型·阶段 / 当前步骤 / 状态 / 产物版本 / 更新时间。点行恢复任务到断点。顶部"＋ 新建评审"。

## 7. 配置管理（FR-14，全部留痕可回滚）

左侧导航四块：
- **评分模板**：四套模板卡片（维度+权重），编辑/历史/回滚；下方变更留痕列表。
- **识别规则**：类型关键词组（六类）、子领域关键词（9 类）、阶段/组合判定参数（识别范围字符数、阶段关键词、年份范围）。
- **范文库**：导入/批量管理，列表含元数据（类型/阶段/子领域/引用次数），可停用（停用不参与检索）。强调"按关联性匹配，禁止固定取前 N 条"。
- **检索参数**：K 值、嵌入模型（bge-m3）、向量库（sqlite-vec）、规则过滤维度、LLM 接入、流式开关、温度。密钥不走此页（走 .env）。

## 8. 评审标准说明（FR-15，只读）

BR-1~BR-5 文档页：顶部锚点目录，正文含四套模板表格、识别规则、组合评审、Word 填表规范、意见内容规范。供秘书与专家查阅。

## 9. 硬性约束落点对照

| 约束 | 原型落点 |
|------|---------|
| 规则配置化零硬编码 | 配置管理页四块全部可视化编辑 |
| 识别可人工干预 | 信息确认页六项可改+留痕 |
| 生成须人工确认 | 人工确认门②（定稿才出产物） |
| 全过程结构化存档可追溯 | 任务列表 + 配置留痕 + 文件级版本 |
| 范文按关联性匹配 | 范文库页明示 + 检索参数页 K 值/规则过滤 |

## 10. 非目标（本期不做）

- 后端实现、真实 LLM 调用、真实 SSE（原型用 mock）
- 批量评审、权限/多角色
- bge-m3 真实向量排序（原型仅展示参数入口）
